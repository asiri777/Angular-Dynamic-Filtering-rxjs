# AngularDynamicFilteringRxjs

A small client-side app that filters a list of US states as you type, built with Angular 21 and RxJS.

This project was originally generated with Angular CLI and has been upgraded to [Angular CLI](https://github.com/angular/angular-cli) version 21.

## Prerequisites

Node.js `^20.19`, `^22.12`, or `>=24` (Angular 21 requirement).

## Development server

Run `ng serve` (or `npm start`) for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.

## Build

Run `ng build` (or `npm run build`) to build the project. The build artifacts will be stored in the `dist/` directory.

## Running unit tests

Run `ng test` (or `npm test`) to execute the unit tests via [Vitest](https://vitest.dev/).

## Linting

Run `ng lint` (or `npm run lint`) to lint the project via [angular-eslint](https://github.com/angular-eslint/angular-eslint).

## Further help

To get more help on the Angular CLI use `ng help` or go check out the [Angular CLI Overview and Command Reference](https://angular.dev/tools/cli) page.
